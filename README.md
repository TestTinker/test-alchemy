# Playwright TypeScript Automation

Structured Playwright framework scaffold with separate layers for tests, flows, pages, API clients, fixtures, utilities, configuration, hooks, integrations, and knowledge-base documentation.

## Getting Started

```bash
npm install
npm test
```

## Layout

- `tests/` executable test suites grouped by strategy
- `flows/` reusable business actions
- `pages/` page objects
- `api/` API clients, endpoints, and models
- `fixtures/` Playwright fixture composition
- `skills/` project knowledge base
